# 奇門遁甲 · 行動指引

依日期時辰自動起奇門盤，找出吉方，再用手機指南針把吉方對到實際方向，並可請 AI 解盤。

**線上使用**：https://kftseng2oo1.github.io/cheman/

## 主要功能
- 自動起盤：計算日／時干支、節氣、旬首、局數，排出九宮的八門、九星、八神
- 依問題類別（事業、感情、財運、健康、決策、趨吉）找出吉方
- 🧭 指南針對位：顯示手機方向與吉方的角度差，直接轉身就能對準
- AI 解析盤面並給行動建議，會主動提出追問
- 起盤紀錄可回看；盤面可下載成圖片或分享

## 使用方式
1. 按「⏱ 現在」或自選日期時辰，選問題類別
2. 按「☯ 起盤解析」
3. 按「🧭 開啟感應器」對準吉方

## 技術與依賴
- 單檔 HTML PWA（`index.html` 內含全部 HTML/CSS/JS），`manifest.json` + `sw.js` 提供安裝到主畫面與離線快取。
- AI 經 `arcar.kftseng2oo1.workers.dev` 代理
- `DeviceOrientation`、Canvas、Web Share
